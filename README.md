# Telegram AI Coach - Тактический Коуч-Ассистент 🤖🤝

Интеллектуальное веб-приложение Telegram Mini App (TMA), которое анализирует ваши переписки, обучается на пользовательских регламентах и скриптах (руководствах) и генерирует готовые тактические ответы для достижения ваших стратегических целей.

## Основной функционал

1. **💻 Нативный интерфейс Telegram Mini App**
   - Полная интеграция с дизайном Telegram: цветовая палитра тёмной темы (`#17212B`), скругленные углы и оптимизированные для пальцев сенсорные зоны (touch targets).
   - Интеграция SDK Telegram WebApp с поддержкой виброотклика (Haptic Feedback) через `window.Telegram`.
   - Автоматическая безопасная валидация `initData` на бэкенде с помощью сигнатуры Бота.

2. **💬 Умный Чат (стиль ChatGPT)**
   - Подключение напрямую к любым передовым LLM через API OpenRouter (Claude 3.5, GPT-4o, DeepSeek, Gemini).
   - Поддержка скользящего окна контекста (последние 20 сообщений) для экономии токенов.
   - Оценка затрат токенов и отображение названия модели под каждым ответом.
   - Поддержка форматирования Markdown и подсветки синтаксиса в коде.

3. **📚 Кастомная База Знаний (Инструкции и Скрипты)**
   - Создание, редактирование и удаление собственных руководств и скриптов переписки.
   - Классификация по категориям: *Переговоры*, *Продажи*, *Отношения*, *Продукт*, *Психология*.
   - Теневое подмешивание включенных инструкций прямо в `system prompt` текущего диалога с ИИ.
   - Предустановленные профессиональные шаблоны: *Гарвардский метод переговоров (BATNA)*, *B2B Sales High-Ticket Closer*, *Техника мирного диалога в семье*.
   - Импорт и экспорт базы знаний в JSON-файловую структуру для быстрого обмена.

4. **🔍 Анализатор Переписок Telegram**
   - Двухэтапная безопасная авторизация: ввод телефона ➡️ генерация разового кода подтверждения (SMS/Служебное сообщение).
   - Вывод списка последних диалогов пользователя из Telegram.
   - Детальный разбор контекста ИИ по заданным целям (например: *"убедить клиента на аванс в $5000"*).
   - Формирование структурированного дашборда:
     - Оценка шансов успеха переписки от 1 до 10.
     - Сильные стороны текущей беседы (Что работает).
     - Допущенные ошибки и красные флаги (Что не работает).
     - Конкретные тактические советы по дальнейшему шагу.
     - **3 проработанных шаблона ответов** с кнопкой мгновенного копирования или импорта в Коуч-Чат для адаптации.

5. **⚙️ Глубокие Настройки**
   - Локальное сохранение API-ключа OpenRouter (ключ отправляется напрямую, бэкенд не имеет к нему доступа).
   - Переключение языковой локализации приложения (Русский 🇷🇺 / English 🇺🇸).
   - Переключатель **"Экспертного режима"** — удаляет лишнюю вежливость ИИ и заставляет давать бескомпромиссные, прагматичные тактические манипуляции.

## Архитектура файлов проекта

```
/project
  /src
    /components
      ChatView.tsx       # Чат-интерфейс, инжекция инструкций в prompt
      ManualsView.tsx    # Библиотека скриптов и локальные шаблоны
      AnalyzerView.tsx   # Дашборд анализа переписок, симуляция логов
      SettingsView.tsx   # API ключи, экспорт базы, выбор моделей
    App.tsx              # Контроллер вкладок, сбор параметров сессии
    types.ts             # Единые типы данных (TypeScript)
    index.css            # Стилизация Telegram-Theme и Markdown
  server.ts              # Экспертный Express-сервер, верификатор initData
  package.json           # Зависимости и скрипты упаковщика
```

## Быстрый Старт

### Настройка переменных окружения

Создайте файл `.env` в корневой директории (по шаблону `.env.example`):

```env
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ТЕЛЕГРАМ_БОТА"
```

### Запуск в режиме разработки

Для запуска сервера разработки (Express + Vite) на порту `3000`:

```bash
npm run dev
```

Откройте в браузере: `http://localhost:3000`

### Сборка проекта для продакшена

Для очистки и компиляции полного full-stack билда (клиент собирается в `dist/`, а TypeScript бэкенд упаковывается в отказоустойчивый `dist/server.cjs` через esbuild):

```bash
npm run build
npm start
```
